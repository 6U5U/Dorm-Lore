# Dorm Lore

Every floor has stories. Yours deserves an archive.

Dorm Lore is a planned private, invite-only home for the quotes, photos, and absurd moments that become your dorm's unofficial history.

> **The Great Microwave Evacuation**  
> September 14, 11:42 PM. One bag of popcorn. Three fire trucks. Six competing eyewitness accounts.

*Example story is fictional.*

## First version

- **Submit a moment:** give it a dramatic title, tell the story, and record when it happened.
- **Browse the timeline:** revisit the floor's history, newest first.
- **Vote it into legend:** each member gets one vote per moment; five votes earns a Legendary badge.

## Next up

Invite codes, member accounts, photo attachments, witness comments, and a Hall of Fame.

## Community rules

Keep it funny and consensual. Ask before posting someone's photo, avoid personal information, and give members a way to report or request removal of a post.
